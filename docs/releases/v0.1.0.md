# v0.1.0 — Initial Standalone DEG Application

Released: 2026-10-25

## Highlights

- Initial Container-as-a-Function application for tabular differential
  expression analysis, suitable for command-line, HPC, and OncoChat use.
- Stable `/data` input and `/output` result conventions, with adapter-owned
  `tables/`, `figures/`, `logs/`, `run_manifest.json`, and `RUN_METADATA.md`
  outputs.
- Canonical OMIX DEG v0.4.4 is byte-preserved and verified in CI against OMIX
  commit `e95a2bb737fa527294aa515a8978702fcdb7b295`.
- Supports observed integer raw counts and fractional RSEM `expected_count`
  values without rounding. TPM, FPKM, CPM, log-transformed, and other
  normalized-expression values remain outside the raw-count contract.
- Restricts the standalone public interface to table input and `raw_counts`
  analysis. MOO and continuous-expression workflows remain available only in
  canonical OMIX.

## Verification

- GitHub Actions verifies the byte-preserved OMIX export, builds the
  linux/amd64 image, runs the public-entrypoint smoke test, and confirms
  canonical-output parity.
- CodeQL completed successfully for the release source commit.
